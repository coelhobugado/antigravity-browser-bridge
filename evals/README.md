# Avaliações beta

`antigravity-baseline.json` contém vinte cenários reproduzíveis para medir leitura, escrita, segurança e recuperação. Eles são um contrato de avaliação, não uma autorização para operar contas reais.

Execute publicações, respostas e exclusões somente em contas de teste e após confirmação explícita. Registre evidências sem armazenar cookies, tokens, mensagens privadas ou dados pessoais.
